    How to use VoiceStack

    VoiceStack lets customers book local shops by voice or text, without double-bookings. Three views, one for each kind of user. Switch with the tabs at the top.

    Quick 2-minute tour
    1. Shop owner tab → Load 3 sample shops (or paste your own message and publish).
    2. Customer tab → tap a suggestion like kal shaam 5 baje haircut, then Yes, confirm.
    3. Go back to Shop owner: your booking is in the table, calendar and audit log.
    4. On Customer, press Another customer wants this slot, then Cancel my booking: the waiting customer is offered the slot.
    5. Developer tab → Run the race to see 20 customers fight for one slot.
    Customer view
    • Pick a shop at the top right. Type, or press 🎤 and speak in Hindi or English; your words land in the box so you can fix them, then press Send.
    • The assistant needs a service, a day and a time. If something is missing it asks, and remembers what you already said.
    • It then holds the slot for 2 minutes and reads it back. Only Yes, confirm books it.
    • The coloured badge shows the real state: Held, Confirming, Confirmed, Hold expired, Conflict, Outcome unknown.
    • If the slot is taken you get free times to tap, or you can join the waitlist.
    Shop owner view
    • Set up: paste a message ("haircut 300 30min, open 10-8, closed sunday"), press Extract draft. Amber warnings tell you what was assumed. Nothing is bookable until you press Approve & publish.
    • Bookings: pick a date, filter by status, cancel a booking. Totals count only what is recorded.
    • Audit log: every change for this shop, including refused attempts (slot taken, expired hold).
    Developer view
    • Every page action is a real MCP call to /mcp. The inspector lists them with tool name, outcome and latency; arguments are hidden unless you tick the raw log.
    • Run the race fires N parallel hold requests for one slot.
    • Server box: version and the 8 tools the server advertises.
    Start fresh

    Stop the server (Ctrl+C), delete the voicestack.db file, start it again.
